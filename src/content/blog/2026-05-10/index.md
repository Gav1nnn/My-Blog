## 前言

最近在准备秋招和后端项目时，越来越容易遇到一个问题：如果想做一个和大模型、RAG、Agent 相关的项目，是不是必须先系统学习深度学习、Transformer、NLP 这些内容？

答案是：**需要学，但不需要一开始就按照算法岗或研究岗的深度去学。**

对于后端开发、Go微服务、Agent工程化方向来说，我们真正需要的是：

- 知道神经网络大概是如何学习的；
- 理解 Transformer 为什么成为大语言模型的核心架构；
- 理解 NLP 与大模型、RAG、Agent 的关系；
- 能够把这些知识落到工程系统里，例如知识库问答、工具调用、智能工作流等场景。

本文会从工程开发者的视角，系统梳理三个核心基础：
1. 神经网络；
2. Transformer；
3. NLP，自然语言处理。

这篇文章不追求数学推理，而是帮助开发者建立一套清晰的认知框架

## 一、整体关系：AI、神经网络、Transformer、NLP 到底是什么关系？

在正式展开之前，先把几个概念之间的关系理清楚。

从大到小可以这样理解：
```text
人工智能 AI
 └── 机器学习 Machine Learning
      └── 深度学习 Deep Learning
           ├── 神经网络架构：MLP、CNN、RNN、LSTM、GNN、Transformer 等
           └── 应用方向：NLP、CV、推荐系统、语音识别、多模态等
```

其中：
- **神经网络** 是深度学习的基础模型结构；
- **Transformer** 是一种非常重要的神经网络架构；
- **NLP** 是自然语言处理，是 AI 的一个重要应用方向；
- **大语言模型 LLM** 通常基于 Transformer 架构，并主要服务于 NLP 及更广泛的智能任务；
- **Agent** 则是在 LLM 之上，结合记忆、工具调用、任务规划、外部系统执行等能力形成的工程系统。

所以，我们学习这些基础不是为了自己训练一个大模型，而是为了更好地理解：

- 大模型为什么能理解和生成文本；
- RAG为什么需要Embedding；
- Agent为什么可以调用工具；
- 如何把大模型能力接入真实后端系统。

## 二、神经网络：深度学习的基本构件

### 2.1 什么是神经网络？

神经网络是一类受到人脑神经元启发的计算模型。它的本质可以理解为：

> 通过大量参数，对输入数据进行多层变换，最终得到一个预测结果。

一个最简单的神经网络通常包括：

```text
输入层 → 隐藏层 → 输出层
```

例如，我们想预测一个学生是否会挂科，可以把以下信息作为输入：

```text
出勤率、作业分数、课堂表现、期末考试分数
```

神经网络经过多层计算后，输出：

```text
挂科概率：0.82
```

在这个过程中，模型会通过训练不断调整内部参数，使得预测结果越来越接近真实结果。

-----

### 2.2 神经网络中的几个核心概念
#### 1. 输入Input
输入就是模型接收的数据。

在不同任务中，输入形式不同：

- 图像任务：输入是一张图片的像素矩阵；
- 文本任务：输入是一段文字对应的 Token 序列；
- 推荐系统：输入可能是用户特征、物品特征、历史行为；
- 风控系统：输入可能是交易金额、登录 IP、设备信息等。

#### 2. 参数Parameter

参数是神经网络真正”学习“的东西。
模型训练的过程，本质上就是不断调整参数，让模型从数据中总结规律。
对于大模型来说，常见的说法比如：

```text
7B 模型、13B 模型、70B 模型
```

这里的 B 是 Billion，也就是十亿。7B 模型大约有 70 亿个参数。

参数越多，模型理论表达能力越强，但也意味着：
- 训练成本更高；
- 推理成本更高；
- 显存占用更大；
- 部署难度更高；

#### 3. 前向传播Forward Propagation

前向传播就是数据从输入层一路经过网络，最后得到输出结果的过程。

例如：
```text
输入图片 → 卷积层提取特征 → 分类层判断类别 → 输出“猫”
```

对于大语言模型（LLM）来说，可以理解为：
```text
输入 Prompt → 模型计算上下文表示 → 预测下一个 Token
```

#### 4. 损失函数Loss Function

损失函数用于衡量模型预测结果和真实答案之间的差距。
比如真实标签是“猫”，模型却预测成“狗”，损失就会比较大。
训练的目标就是让损失尽可能小。

#### 5. 反向传播Back Propagation

反向传播是神经网络训练的核心算法之一。
它会根据损失函数的结果，反向计算每个参数对错误的影响，然后调整参数。
简单理解：
```text
预测错了 → 找出哪些参数导致错 → 调整这些参数 → 下次预测更准
```

#### 6. 训练与推理

训练和推理是两个不同的阶段。
**训练 Training**：

```text
用大量数据调整模型参数
```

**推理 Inference**：

```text
模型参数已经固定，输入新数据后生成结果
```

对于后端开发者来说，我们大多数时候接触的是推理阶段。例如调用 OpenAI API、调用本地 Ollama 模型、接入向量模型生成 Embedding，本质上都是在使用已经训练好的模型进行推理。
-----

### 2.3 常见神经网络类型

神经网络并不是只有一种结构。不同任务通常会使用不同的网络架构。

#### 1. 前馈神经网络 MLP

MLP，也叫多层感知机，是最基础的神经网络。

它的结构非常直接：

```text
输入层 → 若干隐藏层 → 输出层
```

数据只会从前向后流动，没有循环结构。

它适合处理一些基础分类和回归问题，例如：

- 判断用户是否流失；
- 预测房价；
- 判断交易是否异常；
- 根据特征做分类。

MLP 是理解其他复杂神经网络的基础。

#### 2. 卷积神经网络 CNN

CNN 主要用于图像处理。

它擅长从图片中提取局部特征，例如：

- 边缘；
- 纹理；
- 形状；
- 局部区域模式。

典型应用包括：

- 图片分类；
- 人脸识别；
- 目标检测；
- 医学影像分析；
- 自动驾驶视觉感知。

可以这样理解 CNN 的工作过程：

```text
底层识别边缘和颜色
中层识别眼睛、鼻子、轮廓
高层识别猫脸、汽车、行人等对象
```

如果你的方向是 Agent 后端开发，CNN 不需要深入掌握，但要知道它是图像领域非常经典的神经网络。

#### 3. 循环神经网络 RNN

RNN 主要用于处理序列数据。

序列数据包括：

- 文本；
- 语音；
- 时间序列；
- 日志序列；
- 用户行为序列。

RNN 的特点是：

> 当前时刻的输出会受到之前状态的影响。

例如输入一句话：

```text
我今天很开心，因为……
```

模型需要记住前面的“开心”，才能更好地预测后续内容。

但是普通 RNN 有明显缺点：

- 长文本容易遗忘前文；
- 训练慢；
- 难以并行；
- 容易出现梯度消失问题。

因此，后来出现了 LSTM 和 GRU。

#### 4. LSTM / GRU

LSTM 和 GRU 是 RNN 的改进版本。

它们解决的核心问题是：

> 普通 RNN 难以记住较长距离的信息。

LSTM 中引入了“门控机制”，包括：

- 遗忘门；
- 输入门；
- 输出门。

这些门可以控制哪些信息应该保留，哪些信息应该忘掉。

在 Transformer 出现之前，LSTM 曾经是 NLP 领域非常重要的模型结构，常用于：

- 机器翻译；
- 文本分类；
- 语音识别；
- 序列预测。

现在，NLP 主流模型基本已经被 Transformer 替代，但理解 RNN/LSTM 有助于理解 Transformer 为什么重要。

#### 5. 自编码器 AutoEncoder

自编码器的目标是：

> 把数据压缩成一个低维表示，再尽可能还原原始数据。

结构可以理解为：

```text
输入 → 编码器 Encoder → 压缩表示 → 解码器 Decoder → 输出
```

它常用于：

- 数据降维；
- 去噪；
- 异常检测；
- 特征学习。

比如输入一张带噪声的图片，AutoEncoder 可以学习如何还原出更干净的图片。

从工程角度看，自编码器和 Embedding 有一定相似思想：都是把复杂数据压缩为某种有意义的表示。

#### 6. 生成对抗网络 GAN

GAN 由两个网络组成

```text
生成器 Generator
判别器 Discriminator
```

它们之间是对抗关系。

生成器负责伪造数据，例如生成一张图片；判别器负责判断这张图片是真的还是假的。两者不断博弈，最终生成器可以生成越来越真实的数据。

GAN 常用于：

- 图像生成；
- AI 换脸；
- 图像修复；
- 风格迁移；
- 超分辨率。

#### 7. 图神经网络 GNN

GNN 用于处理图结构数据。
图结构由节点和边组成，例如：

```text
用户 A —— 用户 B —— 用户 C
```

典型场景包括：

- 社交网络；
- 知识图谱；
- 推荐系统；
- 风控关系网络；
- 分子结构预测；
- 服务调用拓扑分析。

GNN 会让节点吸收邻居节点的信息，从而更新自己的表示。

例如在风控系统中，如果一个账号和大量异常账号存在关联，那么它的风险评分可能也会升高。

#### 8. Transformer

Transformer 也是一种神经网络架构，但它的重要性远远超过普通架构。

现代大语言模型，如 GPT 系列、LLaMA 系列等，核心思想都与 Transformer 有关。

Transformer 最重要的机制是：

```text
Self-Attention 自注意力机制
```

它让模型在处理一个 Token 时，可以关注上下文中其他 Token，从而理解更复杂的语义关系。

对于 Agent 开发来说，Transformer 是最应该重点理解的神经网络架构。

## 三、Transformer：现代大语言模型的核心架构

### 3.1 Transformer 解决了什么问题？
在Transformer之前，NLP中常用RNN、LSTM处理文本。

但它们有几个问题：

1. 长文本信息容易丢失；
2. 训练很难并行；
3. 捕捉远距离依赖能力有限。

比如一句话：
```text
虽然这部电影的前半段节奏很慢，人物关系也比较混乱，但后半段的反转非常精彩，所以我最终觉得它很好看。
```

模型要判断这句话的整体情感，不能只看前半段“节奏很慢”“比较混乱”，还要看到后半段“反转非常精彩”“很好看”。

RNN/LSTM 在长文本上容易遗忘前面的信息，而 Transformer 通过 Attention 机制，可以让每个 Token 直接和其他 Token 建立关系。

这就是 Transformer 的强大之处。
-----

### 3.2 Tokenization：大模型如何读取文本？

大模型并不是直接读取中文或英文句子，而是先把文本切成Token。
例如：
```text
我喜欢 Go 语言
```
可能被切成：
```text
["我", "喜欢", "Go", "语言"]
```

英文单词也可能被拆成子词。例如：

```text
unbelievable
```

可能被切成：

```text
["un", "believable"]
```

Token 是大模型处理文本的基本单位。

这对工程开发很重要，因为：

- 上下文窗口按 Token 计算；
- API 计费通常按 Token 计算；
- Prompt 太长会导致成本和延迟上升；
- RAG 拼接文档时要控制 Token 数量。

-----

### 3.3 Embedding：把文本变成向量

Token本身是离散符号，模型无法直接理解它们的语义。
因此，需要把token转成向量，这个过程叫Embedding。
例如：
```text
"猫"  → [0.12, -0.33, 0.88, ...]
"狗"  → [0.10, -0.30, 0.81, ...]
"汽车" → [-0.72, 0.44, 0.13, ...]
```
在向量空间中，语义想近的词，向量距离通常也更近。

比如：
